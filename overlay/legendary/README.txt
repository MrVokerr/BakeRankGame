================================================================================
👑 LEGENDARY ITEMS FOLDER
================================================================================

Place your RARE / LEGENDARY items in this folder!

HOW IT WORKS:
-------------
1. Any .png file in this folder is automatically treated as LEGENDARY.
2. Legendary items have a 1% drop chance.
3. They trigger special effects and give more points (5 pts).

EXAMPLES:
---------
File: GoldenCake.png       → Chat shows: "baked a LEGENDARY Golden Cake!"
File: ExcaliburBread.png   → Chat shows: "baked a LEGENDARY Excalibur Bread!"

NOTE:
-----
You do NOT need to add "Legendary-" to the filename anymore if you put them here.
Just name them normally (e.g., "WeddingCake.png").
